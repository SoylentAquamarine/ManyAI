What it does

🔀

Smart routing

Automatically picks the best available free provider for each task type — fastest for quick questions, most capable for reasoning.

⚡

Silent fallback

If a provider fails, hits a rate limit, or times out, ManyAI silently tries the next one. You never see the error.

🔑

Your keys, your device

All API keys are encrypted using your device's secure enclave. Nothing ever reaches a ManyAI server.

📊

Compare mode

Send the same prompt to all providers at once and compare responses side by side.

📷

Vision support

Attach photos or use your camera — automatically routed to vision-capable providers (Gemini, OpenAI).

💾

Save responses

Save any AI response to a custom category — Recipes, Code, Research, Ideas, and more.

Get Started

1
Install Expo Go

Download Expo Go on your Android or iPhone from the app store.

2
Clone and run

git clone https://github.com/SoylentAquamarine/ManyAI.git && npx expo start

3
Add free API keys

Open Settings → API Keys. Get free keys from Cerebras, Groq, Gemini, Mistral, and SambaNova — all free, no credit card.

Tip: Go to qr.io on your laptop, paste an API key, generate a QR code, then tap the QR button in the app to scan it in — no typing needed.
